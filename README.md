#Student Records Management System

A menu-driven **Student Records Management System** developed using the **C programming language** and a **Singly Linked List**.
This project allows users to dynamically manage student records, including adding, deleting, modifying, sorting, saving, restoring, reversing, and deleting records.

Features

- Add new student records
- Automatically assign unique roll numbers
- Assign the smallest available positive roll number
- Delete records by roll number
- Delete records by name
- Display all student records
- Modify records by roll number
- Modify records by name
- Modify records by percentage
- Save student records to a file
- Restore student records from a file
- Sort records alphabetically by name
- Sort records by percentage in descending order
- Reverse the linked list
- Delete all student records
- Save and exit
- Exit without saving
- Input validation for student details

Student Record Structure

Each student record contains the following information:

- Roll Number
- Name
- Percentage

The records are dynamically stored using a **Singly Linked List**.

Menu Options

A/a : Add new record
D/d : Delete a record
S/s : Show the list
M/m : Modify a record
V/v : Save records
B/b : Restore records
T/t : Sort the list
L/l : Delete all the records
R/r : Reverse the list
E/e : Exit
